# Economic Statistics Analyzer (경제통계분석기)

엑셀로 받은 경제통계 자료를 올리면 **증감률·이동평균·성장 기여도·상관관계**를 자동으로 계산하고, 표와 그래프로 보여 주며, 결과를 엑셀로 내려받을 수 있는 웹 앱입니다. KOSIS 국가통계포털에서 받은 원본 엑셀을 고치지 않고 그대로 올릴 수 있습니다.

> 이 프로그램은 KOSIS 등에서 내려받은 공개 통계 엑셀을 분석하기 위한 **별도의 도구**이며, KOSIS·통계청의 공식 서비스가 아닙니다.

## 무엇을 하나요

엑셀로 통계표를 다룰 때 매번 하던 일 — 수식으로 증감률을 계산하고, 그래프를 만들고, 결과를 정리하는 일 — 을 파일 업로드 한 번으로 줄입니다.

| 지표 | 설명 |
|---|---|
| 전년동기대비 증감률 | 같은 달(분기)의 1년 전 값과 비교한 증감률(%) |
| 전월대비 증감률 | 바로 전달과 비교한 증감률(%) — 월별 자료만 |
| 3개월 이동평균 | 최근 3개월 평균 — 월별 자료만 |
| 성장 기여도 | 항목이 전체 증감에 기여한 정도(%p) |
| 상관관계 | 전년동기대비 증감률 기준 항목 간 상관계수 |

## 주요 기능

- **KOSIS 원본 엑셀 업로드**: A~C열의 대분류·중분류·세부 품목과 D열부터의 날짜별 수치를 자동으로 인식해 날짜는 행으로, 품목은 열로 바꿉니다. 원본 수치와 단위는 바꾸지 않습니다.
- **변환 미리보기와 품목 선택**: 계산 전에 변환 결과를 보고, 세부 품목·중분류 소계·대분류 소계 중 한 단위를 골라 계산합니다. 소계와 세부 품목은 함께 쓰지 않아 중복 집계되지 않습니다.
- **결측 처리**: KOSIS의 결측("-")은 값을 채우지 않고 "결측"으로 두며, 그 값이 걸린 계산만 "계산 불가"로 표시합니다.
- **직접 만든 양식 지원**: `데이터` 시트(날짜×항목)와 `비중` 시트(항목별 비중 %)를 둔 엑셀도 올릴 수 있습니다. 빈 칸이나 문자가 있으면 계산을 멈추고 시트·행·열 위치를 알려 줍니다.
- **결과 페이지**: 기준 시점의 핵심 수치 카드(가장 크게 증가·감소한 항목, 성장 기여도 1위 등), 구역으로 바로 이동하는 고정 탭, 증가는 파랑·감소는 빨강으로 칠한 표와 상관관계 색 지도.
- **그래프**: 시계열 추세(항목 최대 5개, 지표 선택)와 항목별 비교(기준 시점 선택, 상위·하위 10개 막대).
- **엑셀 내려받기**: 원자료·증감률·이동평균·기여도·상관관계를 지표별 시트로 담은 `.xlsx` 파일.
- **다운로드 안내 페이지**: KOSIS에서 어떤 설정으로 엑셀을 받아야 하는지 단계별로 안내합니다 (`/guide`).

## 사용 방법

1. 첫 화면에서 **분석 시작하기**를 눌러 업로드 구역으로 이동하고, 샘플 파일(`/samples`, 가상 숫자)이나 KOSIS에서 받은 엑셀을 올립니다.
2. 결과 페이지(`/analyze`)로 넘어가 파일을 읽습니다. KOSIS 원본이면 변환 미리보기에서 통계항목·분석 단위·품목을 고릅니다.
3. 핵심 요약 카드, 그래프, 색으로 증감을 보여 주는 표를 확인하고, 필요하면 엑셀로 내려받습니다.

> 올린 파일은 브라우저 탭의 메모리에만 있습니다. 결과 페이지에서 새로 고침하면 사라지므로 첫 화면에서 다시 올려 주세요.

## 개인정보와 보안

- 올린 파일과 계산 결과는 **서버에 저장하지 않습니다.** 요청을 처리하는 동안만 메모리에서 사용합니다.
- 외부 서비스로 자료를 보내지 않으며, 이 앱은 API 키를 사용하지 않습니다.
- **공개된 통계 자료만** 올려 주세요. 개인정보나 비공개 자료는 올리지 않습니다.

## 직접 실행하기

```bash
npm install
npm run dev        # http://localhost:3000
```

```bash
npm run build      # 배포용 빌드
npm run lint       # 코드 검사
npm run verify     # 계산 검증 (아래 참고)
npm run samples    # 샘플 엑셀(가상 숫자) 다시 만들기
```

### 계산 검증

`npm run verify`는 `public/samples/`의 샘플 3종과 `samples-kosis/`의 KOSIS 원본 파일에 대해, 앱의 계산 결과를 엑셀 식을 그대로 따라 쓴 별도 계산과 칸마다 비교합니다. KOSIS 파일은 원본 수치·단위가 변환 후에도 그대로인지, 소계와 세부 품목이 섞이지 않는지도 확인합니다. (엑셀 프로그램이 직접 계산한 값과의 비교가 아니라, 같은 식을 독립적으로 구현해 맞춰 보는 방식입니다.)

## 폴더 구조

```
app/              화면(첫 화면, /analyze 결과, 안내 페이지)과 서버 API (/api/analyze, /api/export)
components/       첫 화면 히어로, 업로드, 미리보기, 결과 카드·표, 그래프, 헤더 등 화면 부품
lib/stats/        엑셀 읽기, KOSIS 변환, 지표 계산, 내보내기
public/samples/   가상 숫자 샘플 엑셀 3종
samples-kosis/    검증용 KOSIS 원본 엑셀
scripts/          샘플 생성, 계산 검증 스크립트
```

## 참고

- `samples-kosis/`의 파일은 KOSIS 국가통계포털에서 내려받은 공개 통계(품목별 수출액)이며, 출처는 한국무역협회 「SITC에의한무역통계」입니다. 이용 조건은 KOSIS의 안내를 따릅니다.
- `public/samples/`의 샘플 숫자는 모두 **가상**이며 실제 통계가 아닙니다.
